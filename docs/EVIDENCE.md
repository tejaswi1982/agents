## Tracker showcase adaptation

Source files outside this package remain untouched. The packaged copy:

- Calls the existing `buildSample()` at load.
- Makes `save()` a no-op, so changes do not persist.
- Adds a visible fictional-data note and a no-index instruction.
- Replaces em/en dash punctuation with commas or hyphens to meet the site preference.
- Routes the optional back link to Agents.
- Retains the supplied UI, calculations, report, manual drafts and sample generator.

The iframe permits scripts and user-initiated downloads, without same-origin privileges. Nothing is automatically sent. The standalone prototype has the same ephemeral data behaviour. Its report is a demonstration, not a clinical or commercial result.

## Public demo limitations

The BCCL demo generated options during inspection, but its current Choose screen did not expose usable selection controls. The case-study run provides the stronger visible evidence of the full loop. The showcase links to both and does not claim the current external demo was verified end to end.

The Content Supply Chain demo was exercised through option selection, feedback and localisation. Final approval/export was not exercised. Both creative demos describe an offline generator. That limitation is preserved in visible captions and build notes.
